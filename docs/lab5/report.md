## Задание 3. Консольное приложение для работы с массивами на Objective-C

### Постановка задачи варианта 6

Найти максимальное число в массиве
`NSArray *numbers = @[@15, @25, @5, @10, @20]`.

### Структура проекта

- `task3/src/ArrayManager.h` — публичный интерфейс
- `task3/src/ArrayManager.m` — реализация и приватные методы через class extension
- `task3/src/main.m` — запуск приложения

### Результат

Программа демонстрирует:

- вывод неизменяемого массива;
- создание пустого `NSMutableArray`;
- ввод элементов массива с консоли;
- подсчёт количества элементов;
- добавление;
- вставку по индексу;
- удаление последнего элемента;
- удаление по индексу;
- удаление всех элементов;
- поиск максимума в заданном массиве.

### Протокол тестирования

| № | Входные данные | Ожидаемый результат | Действительный результат | Тест |
|---|---|---|---|---|
| 1 | `4 8 15 16 23 42`, затем `99`, `7`, `2`, `3` | Максимум `25`, корректное выполнение всех операций над mutable-массивом | После операций получен массив `[4, 8, 7, 16, 23, 42]`, затем `[]` после `removeAllObjects` | Пройден |
| 2 | пустой ввод массива, затем `10`, `20`, `0`, `5` | Корректная обработка пустого массива и выхода за границы индекса | Приложение вывело `Mutable array after console input: []` и `Removal by index skipped because the index is out of bounds.` | Пройден |

### Ответы на вопросы

1. Для получения количества элементов в `NSArray` используется свойство
   `count`.
2. Правильные способы создать пустой mutable-массив:
   - `NSMutableArray *array = [[NSMutableArray alloc] init];`
   - `NSMutableArray *array = [NSMutableArray array];`
3. Для добавления элемента в конец mutable-массива используется метод
   `addObject:`.
4. При обращении по индексу вне границ массива возникает ошибка времени
   выполнения (`NSRangeException`).
5. Последний элемент можно получить через `lastObject`.

## Задание 4. Консольные приложения на Swift: способы создания

### Постановка задачи варианта 6

Дано натуральное четырёхзначное число. Выяснить, является ли оно палиндромом.

### Реализация

- `task4/palindrome.swift` — консольный Swift-скрипт
- `task4/Palindrome.playground/Contents.swift` — Playground-версия
- `task4/repl-session.md` — пример работы в Swift REPL

### Что продемонстрировано

- запуск скрипта командой `swift palindrome.swift`;
- компиляция командой `swiftc palindrome.swift -o palindrome_checker`;
- подготовка Playground и примера REPL-сеанса.

### Протокол тестирования

| № | Входные данные | Ожидаемый результат | Действительный результат | Тест |
|---|---|---|---|---|
| 1 | `1221` | Палиндром | `1221 is a palindrome.` | Пройден |
| 2 | `1234` | Не палиндром | `1234 is not a palindrome.` | Пройден |
| 3 | `999` | Сообщение об ошибке, так как число не четырёхзначное | `Error: please enter a natural four-digit number.` | Пройден |

### Ответы на вопросы

1. `Swift REPL` — это интерактивная консоль Swift, в которой можно сразу
   выполнять выражения и проверять небольшие фрагменты кода. Она полезна для
   быстрых экспериментов, отладки идей, проверки синтаксиса и изучения языка.
2. `Playground` — это интерактивная среда Xcode для быстрого прототипирования
   и обучения. В playground удобно создавать небольшие учебные программы,
   алгоритмические примеры, демонстрации работы API и эксперименты с UI/логикой.
3. В консоли bash приложение на Swift компилируется командой
   `swiftc file.swift -o program_name`.

## Задание 7. Консольное приложение для обработки массивов на Swift

### Постановка задачи варианта 6

Разработать класс `StringAnalyzer`, который получает опциональный массив строк
и подсчитывает количество уникальных символов.

### Архитектура MVC

- `Models`:
  - `ArrayRepository.swift`
  - `StringAnalyzer.swift`
- `Views`:
  - `ConsoleView.swift`
- `Controllers`:
  - `AppController.swift`

### Реализованные возможности

- вывод неизменяемого и изменяемого массива;
- создание пустого mutable-массива;
- ввод элементов с консоли;
- подсчёт количества элементов;
- добавление элемента;
- вставка по индексу;
- удаление последнего элемента;
- удаление по индексу;
- очистка массива;
- работа с опциональным массивом строк через `StringAnalyzer`.

### Результаты автоматической проверки

Выполнена сборка `swift build` и тесты `swift test`.
Итог: `3 tests passed`.

### Протокол тестирования

| № | Входные данные / действие | Ожидаемый результат | Действительный результат | Тест |
|---|---|---|---|---|
| 1 | Команда `9` сразу после запуска | Для пустого optional-массива количество уникальных символов равно `0` | `Unique characters count: 0` | Пройден |
| 2 | Ввести `swift code lab`, затем вставить `ios`, добавить `mobile`, выполнить анализ | Корректный подсчёт уникальных символов | `Unique characters count: 13`, `Unique characters: abcdefilmostw` | Пройден |
| 3 | После анализа удалить последний элемент, удалить элемент по индексу, очистить массив | Массив корректно модифицируется и очищается | Получены массивы `[swift, ios, code, lab]`, затем `[swift, code, lab]`, затем пустой массив | Пройден |

### Ответы на вопросы

1. Пустой массив типа `Int` в Swift создаётся так: `var numbers: [Int] = []`
   или `var numbers = [Int]()`.
2. Если массив объявлен как `let`, его размер нельзя менять: методы `append`,
   `insert`, `remove` вызовут ошибку компиляции.
3. Для добавления элемента в конец массива используется метод `append(_:)`.
4. Все элементы массива должны быть одного типа.
5. Фраза «массив является универсальной коллекцией» означает, что массив можно
   параметризовать любым типом, например `[Int]`, `[String]`, `[CustomType]`.
6. Для перебора элементов массива вместе с индексом обычно используется
   `enumerated()`.
