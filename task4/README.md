# Project Name

Task 4. Swift console application, REPL and Playground demonstration.

# Description

This task is implemented for lab work 5, variant 6. The Swift program checks
whether a natural four-digit number is a palindrome. The directory also includes
a Playground file and a short Swift REPL session example.

# Installation

Build the command-line application with `swiftc`:

```sh
swiftc palindrome.swift -o palindrome_checker
```

# Usage

Run the compiled executable:

```sh
./palindrome_checker
```

You can also:

- open `Palindrome.playground` in Xcode;
- run `swift palindrome.swift`;
- experiment in Swift REPL using `swift`.
