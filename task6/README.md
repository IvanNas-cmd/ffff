# Project Name

Task 6. Swift Package Manager console application for dictionary processing.

# Description

This package implements lab work 5, variant 6. The app manages two
dictionaries:

- `Soldier(name, salary)` — starts empty;
- `Department(name, position)` — starts with predefined values.

The console menu supports dictionary creation, input, counting elements,
searching by key, output of all elements, adding, modifying, sorting by key and
value, deleting one element and deleting all elements.

# Installation

Build the package:

```sh
swift build
```

Run tests:

```sh
swift test
```

# Usage

Start the console menu:

```sh
swift run Task6App
```
