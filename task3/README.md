# Project Name

Task 3. Objective-C console application for array processing.

# Description

The application is implemented for lab work 5, variant 6. It demonstrates work
with immutable and mutable arrays in Objective-C and also solves the variant
task: finding the maximum value in the array `@[@15, @25, @5, @10, @20]`.

# Installation

1. Open a terminal in this directory.
2. Build the project:

```sh
make
```

# Usage

Run the program and follow the prompts:

```sh
make run
```

The application demonstrates:

- immutable array output;
- empty mutable array creation;
- console input for mutable array values;
- counting elements;
- appending;
- inserting by index;
- deleting the last element;
- deleting by index;
- deleting all elements.
