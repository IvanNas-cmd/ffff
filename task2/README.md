# Project Name

Task 2. Objective-C console application for Fibonacci calculations.

# Description

The program is implemented for lab work 5, variant 6. It demonstrates the
`@interface`, `@implementation` and `program` structure of an Objective-C
console application. The app reads `k`, generates the first `k` Fibonacci
numbers and calculates their sum.

# Installation

1. Open a terminal in this directory.
2. Build the application:

```sh
make
```

# Usage

Run the program and enter a positive integer:

```sh
make run
```

Example:

```text
Enter k:
7
First 7 Fibonacci numbers: 1 1 2 3 5 8 13
Sum: 33
```
