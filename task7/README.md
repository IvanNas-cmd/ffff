# Project Name

Task 7. Swift MVC console application for array processing.

# Description

This package implements lab work 5, variant 6. The application demonstrates
immutable and mutable arrays, optional data types and classes/structures in a
console project organized using MVC:

- `Models` — array storage and string analysis;
- `Views` — console input and output;
- `Controllers` — workflow and menu logic.

Variant task: `StringAnalyzer` receives an optional array of strings and counts
the number of unique characters.

# Installation

Build the package:

```sh
swift build
```

Run tests:

```sh
swift test
```

# Usage

Start the application:

```sh
swift run Task7App
```
