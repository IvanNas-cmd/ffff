# Lab 7

Swift iOS lab work, variant 17.

## Tasks

- `2.2` graphics demo with a circle segment and a right trapezoid;
- `2.3` animation demo with move, rotate, scale, opacity, and combined effects;
- `2.4` gesture demo that changes the figure background based on gestures.

## Structure

- `ios/Model` - variant data and runtime background generation;
- `ios/View` - custom views for graphics, animation, and gestures;
- `ios/Controller` - the main screen controller;
- `ios/App` - app and scene bootstrap code.
