# Project Name

Task 1. Familiarization with Xcode and iOS Simulator.

# Description

This directory contains the written part for task 1 of lab work 5. The task is
focused on installing Xcode, creating an iOS project in Swift, launching the
iOS Simulator and connecting an Apple ID inside Xcode.

# Installation

No build step is required for this task. You need:

- macOS with Xcode installed;
- access to iOS Simulator;
- an Apple ID for device signing.

# Usage

Recommended execution order in Xcode:

1. Open Xcode.
2. Create a new iOS project in Swift.
3. Choose an iPhone simulator in the active scheme.
4. Run the project with `Cmd+R`.
5. Open `Xcode -> Settings -> Accounts` and add your Apple ID.

Answers to task questions:

1. iOS Simulator can be launched by running a project from Xcode with `Cmd+R`,
   by pressing the Run button in the toolbar, or by opening the Simulator app
   directly from Xcode tools / Spotlight and then selecting a simulated device.
2. The simulator is controlled with the mouse and keyboard; hardware features
   are available through the `Device`, `Features`, `I/O` and `Debug` menus. You
   can rotate the device, simulate gestures, paste text, trigger keyboard input
   and reset the simulated content and settings.
